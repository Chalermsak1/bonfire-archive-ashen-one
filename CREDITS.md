# Credits

The holographic card renderer, authored artwork, models, textures, and original scene are from [ThreeUI's Dark Souls Holo Card](https://threeui.com/hero/dark-souls-holo-card) by Meng To / Design+Code. This project preserves its registered source files byte for byte; their hashes are listed in the README.

The Bonfire Archive page layout, presentation, responsive shell, and load-on-request interaction were built for this Web Programming project. The archive preview images and fonts were extracted from the verified scene source for use in the surrounding page. The 3D document loads Three.js r180 from jsDelivr at runtime.

Dark Souls names and imagery are used here as a fan-inspired programming showcase. This project does not claim ownership of the original game or ThreeUI scene.
